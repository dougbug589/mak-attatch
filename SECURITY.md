# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability, please report it:

1. Open a [GitHub issue](https://github.com/dougbug589/mak-attatch/issues)
2. Include steps to reproduce the issue
3. Leave out secrets such as your TMDB API key

## Supported Versions

Security fixes go into the latest release only. Please update before reporting.

## Scope

- API key handling and storage
- Network request security
- File path handling
- Subprocess execution
- Input validation

## Out of Scope

- TMDB API itself (report to TMDB)
- System packages (ffmpeg, mkvtoolnix)
- Desktop environment vulnerabilities

## Response Time

- Acknowledgment within 48 hours
- Fix or mitigation within 7 days for critical issues
- Credit given to reporters (unless anonymous)
